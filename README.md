# Waste Detection and Recycling Assistant

A multi-model waste detection and recycling assistance project that combines image classification, object detection, rule-based recycling guidance, and RAG-based recommendation for smart waste management.

---

## Introduction

This repository contains the complete work for a waste detection and recycling assistance system developed using multiple deep learning approaches. The project includes several trained models, their training notebooks, performance graphs, output samples, presentations, and a deployable Streamlit web application.

The repository covers the following major approaches:

- **ResNet-50 with rule-based recycling guidance**
- **ResNet-50 + ViT feature-level fusion with rule-based recycling guidance**
- **DenseNet121 + EfficientNetb0 hybrid model with rule-based recycling guidance**
- **YOLOv8 with RAG-based recycling guidance**

The main goal of this project is to detect waste materials from images and provide meaningful recycling assistance. Different models were developed and compared to study their performance for waste classification and waste detection tasks.

---

## Project Objectives

- Build intelligent models for waste classification and detection
- Compare multiple deep learning architectures for performance analysis
- Provide recycling guidance based on detected waste categories
- Develop a user-friendly web application using **Streamlit**
- Organize all training, results, graphs, outputs, and presentations in one repository

## Models Included

### 1. ResNet-50 with Rule-Based Recycling Guidance

A CNN-based image classification approach that predicts the waste category and provides recycling suggestions through predefined rule-based logic.

### 2. ResNet-50 + ViT Feature Fusion with Rule-Based Recycling Guidance

A hybrid model that combines CNN feature extraction with transformer-based global representation to improve waste classification performance.

### 3. DenseNet121 + EfficientNetb0 Hybrid with Rule-Based Recycling Guidance

A feature-level fusion approach that combines DenseNet121 and EfficientNetb0 for waste classification and provides recycling guidance using rule-based recommendations.

### 4. YOLOv8 + RAG-Based Recycling Guidance

An object detection and recommendation system that detects waste items in images using YOLOv8 and generates recycling recommendations using a Retrieval-Augmented Generation pipeline.

## How the System Works

### Classification-Based Models

1. The user uploads an image.
2. The selected classification model predicts the waste category.
3. The system maps the predicted class to recycling guidance using predefined rules.
4. The result is shown in the interface.

### YOLOv8 + RAG Model

1. The user uploads an image.
2. YOLOv8 detects one or more waste objects in the image.
3. Bounding boxes, class labels, and confidence scores are generated.
4. The detected waste labels are passed to the RAG pipeline.
5. The knowledge base is queried to generate recycling recommendations.
6. The final results are shown in the Streamlit web application.

## How to Download and Run the Web Application

### Step 1: Clone the Repository

```bash
git clone https://github.com/JithinKamineni/waste-detection-recycling-assistant.git
cd waste-detection-recycling-assistant
```

### Step 2: Go to the Application Folder

```bash
cd Application
```

### Step 3: Install the Required Dependencies

```bash
pip install -r requirements.txt
```

### Step 4: Run the Streamlit Web App

```bash
streamlit run app.py
```

### Step 5: Open in Browser

After running the above command, Streamlit will provide a local URL such as:

```text
http://localhost:8501
```

Open that URL in your browser to use the web application.

---

## Important Note on Running

This project web application is built using Streamlit, so it is usually run with:

```bash
streamlit run app.py
```

It is not typically run using:

```bash
npm install
npm run
```

Those commands are generally used for Node.js or React applications, not for this Python Streamlit application.
